Technologies Used

    HTML

  • 🐳

    Docker

    Packages the page into a container that runs anywhere.

  • ⚙️

    Jenkins

    Automates the build and deployment on every change.

  • ☁️

    AWS EC2

    Cloud server that hosts the running container.

  • 🐙

    GitHub

    Stores the code and triggers Jenkins with a webhook.

  • 📦

    Docker Hub

    Registry that stores the built Docker images.

  • ☸️

    Kubernetes

    Runs the pods and exposes the site through a NodePort service.
